## 📖 درباره این پروژه

این پروژه نسخهٔ فارسی، راست‌چین، بازطراحی‌شده و تعاملی کتاب محبوب **LPIC-1** بر مبنای محتوای مرجع وب‌سایت **[linux1st.com](https://linux1st.com/)** است.

هدف از این پروژه، فراهم کردن یک مرجع متنی فارسی، دقیق، منظم و مدرن برای تمام علاقه‌مندان به دنیای لینوکس و داوطلبان آزمون‌های بین‌المللی **LPIC-1 (Exam 101 & Exam 102)** است تا بتوانند در کنار ویدیوهای آموزشی، به متنی روان و خوانا دسترسی داشته باشند.

## ✨ ویژگی‌های نسخه جدید فارسی

- 📚 **پوشش کامل سرفصل‌های LPIC-1 نسخه ۵.۰:** شامل تمام ۴۶ درس مربوط به آزمون ۱۰۱ و آزمون ۱۰۲.
- 🎨 **طراحی کاملاً راست‌چین و مدرن (RTL):** تایپوگرافی چشم‌نواز با فونت زیبای «وزیرمتن» (Vazirmatn).
- 🌓 **پشتیبانی از حالت شب و روز (Dark / Light Mode):** با قابلیت ذخیره تنظیمات در مرورگر کاربر.
- 🔍 **موتور جستجوی سریع درون‌برنامه‌ای:** جستجو بر اساس عنوان، مبحث و کلیدواژه بدون نیاز به بارگذاری مجدد صفحه (با کلید میانبر `/`).
- 📋 **کپی آسان خطوط فرمان:** دکمه کپی اختصاصی برای بلوک‌های کد و دستورات ترمینال با تفکیک جهت متن چپ‌به‌راست (LTR).
- 📱 **کاملاً ریسپانسیو (واکنش‌گرا):** بهینه‌سازی شده برای مطالعه روی گوشی‌های هوشمند، تبلت‌ها و دسکتاپ.
- ⚡ **دیپلوی تمام خودکار با GitHub Actions:** سایت با هر کامیت به صورت اتوماتیک بیلد شده و روی GitHub Pages منتشر می‌شود.

## 🛠️ راهنمای اجرای لوکال (Local Setup)

اگر می‌خواهید روی پروژه کار کنید، درسی اضافه کنید یا قالب را ویرایش کنید:

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/Pouyazadmehr83/lpic1-fa.git
cd lpic1-fa
```

### ۲. نصب پیش‌نیازها
```bash
pip install -r requirements.txt
```

### ۳. بیلد و اجرای سرور محلی
```bash
chmod +x start_server.sh
./start_server.sh
```
سپس در مرورگر خود آدرس `http://localhost:8000` را باز کنید.
