## ✨ ویژگی‌ها
- 📖 ترجمه روان و بازنویسی سرفصل‌های رسمی LPIC-1 (ورژن 5.0)
- 🎨 رابط کاربری مدرن، کاملاً واکنش‌گرا و راست‌چین (RTL) با فونت وزیرمتن
- 🌓 پشتیبانی از حالت شب و روز (Dark / Light Mode)
- 🔍 سیستم جستجوی سریع در تمام سرفصل‌ها و مباحث

- 🎬 لینک مستقیم به ویدیوهای یوتیوب مرتبط هر درس از جادی

## 🛠️ اجرای محلی (Local Development)

### پیش‌نیازها
- Python 3.8+
- پکیج‌های پایتون:
  ```bash
  pip install -r requirements.txt
  ```

### ساخت و اجرای سایت
با اجرای اسکریپت آماده:
```bash
./start_server.sh
```
یا به صورت دستی:
```bash
python3 build.py
cd persian-book/site
python3 -m http.server 8000
```
سپس در مرورگر آدرس `http://localhost:8000` را باز کنید.
