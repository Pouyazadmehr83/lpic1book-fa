#### توضیحات

کاندیداها باید بتوانند اسکریپت های موجود را سفارشی کنند یا اسکریپت های ساده Bash جدید بنویسند.

#### حوزه های دانش کلیدی:

* از نحو استاندارد sh \(حلقه ها، تست ها) استفاده کنید.
* از جایگزینی دستور استفاده کنید.
* مقادیر بازگشتی را برای موفقیت یا شکست یا سایر اطلاعات ارائه شده توسط یک فرمان آزمایش کنید.
* دستورات زنجیره ای را اجرا کنید.
* ارسال مشروط به ابرکاربر را انجام دهید.
* مفسر اسکریپت را از طریق خط shebang \(`#!`\) به درستی انتخاب کنید.
* مکان، مالکیت، اجرا و حقوق خود را از اسکریپت ها مدیریت کنید.

#### شرایط و امکانات

* `for`
* `while`
* `test`
* `if`
* `read`
* `seq`
* `exec`
* `||`
* `&&`

## ترکیب دستورات

اگر می خواهید بیش از یک دستور را در یک خط اجرا کنید، آنها را با یک `;` جدا کنید. بنابراین `cd /tmp; ls` `cd /tmp` و سپس `ls` را اجرا می کند. اما کاربردهای پیشرفته تری نیز وجود دارد.

می‌توانید از زنجیره‌بندی `&&` \(به‌عنوان منطقی And\) و `||` \(به‌عنوان منطقی OR\) استفاده کنید. در صورت And، به محض اینکه اولین مورد اجرا نشد، اجرا متوقف می شود. در مورد Or، دستور بعدی فقط در صورتی اجرا می شود که دستور اول ناموفق باشد. درست مثل گیت های منطقی.

گیج کننده؟ بازم توضیح بدم سیستم همیشه سعی می کند نتیجه زنجیره شما را *ارزیابی* کند. بنابراین اگر شما `A && B` دارید، A شکست می خورد، سیستم نیازی به آزمایش B ندارد (زیرا نتیجه کلی به هر حال False خواهد بود). منطق مشابه برای `A || B || C` کار می کند. اگر A خوب کار کند، ارزیابی کلی True خواهد بود، بنابراین نیازی به آزمایش B یا C نیست. اما اگر A شکست بخورد، سیستم B را امتحان می کند و اگر B شکست می خورد، باید C را امتحان کنیم. 

ما از زنجیره برای ایجاد جریان های منطقی استفاده می کنیم. به عنوان مثال:

```
$ cp backup.gzip /backups/ && rm backup.gzip
```

به این صورت عمل می کند: نسخه پشتیبان را در این مکان کپی کنید و فایل را فقط در صورت موفقیت آمیز بودن نسخه قبلی حذف کنید. 


### اسکریپت های پوسته
ما می توانیم دستورات پوسته یا برنامه ها و یا برخی منطق یا حلقه ها را برای نوشتن اسکریپت های بزرگ یا کوچک ترکیب کنیم. اسکریپت های پوسته زمانی مفید هستند که می خواهید برخی از وظایف را در یک دستور بزرگتر *اتوماتیک* کنید. فرض کنید یک اسکریپت پوسته به نام "do_backup.sh" ممکن است برخی از فایل ها را در یک فایل فشرده کند، نام این فایل را بر اساس تاریخ و زمان فعلی تغییر دهید و سپس آن را در یک سایت راه دور ذخیره کنید و در نهایت موارد قدیمی تر از 1 ماه را حذف کنید.

### شبانگ
یک خط در ابتدای اسکریپت ها وجود دارد که با `#!` شروع می شود و با یک فایل اجرایی که نیاز به اجرای این اسکریپت دارد ادامه می یابد. به آن shebang می گویند و همانطور که گفته شد، به پوسته می گوید که برای اجرای این اسکریپت از کدام _interpreter_ باید استفاده شود.

> توجه: در بسیاری از زبان های برنامه نویسی (از جمله Bash و Python)، یک `#` در ابتدای یک خط در اسکریپت نشان دهنده _comments_ است. آن را با _Shebang_ \(`#!`\) اشتباه نگیرید

معمولاً ما اسکریپت های پوسته را با استفاده از `#!/bin/bash` یا `#!/bin/sh` اجرا می کنیم

بقیه یک اسکریپت پوسته می‌تواند از بیشتر دستوراتی که قبلاً می‌شناسید، علاوه بر برخی دستورات خاص «برنامه‌نویسی» مانند حلقه‌ها، تست‌ها و مواردی از این قبیل استفاده کند. در اینجا یک نمونه اولیه وجود دارد:

```bash
#!/bin/bash

echo
echo "We are learning! Wowww..."
echo
```

> `sh` پوسته ابتدایی تری است اما با بسیاری از مواردی که در مورد آنها صحبت می کنیم سازگار است. گزینه‌های دیگری مانند `zsh` و `csh` نیز وجود دارد، اما LPIC بر اساس `bash` است.

### متغیرها
قبلاً در بخش قبل دیده شده است. می توانید متغیرهایی مانند این `VARNAME=VALUE` تعریف کنید. در اینجا یک نمونه است:

```bash
#!/bin/bash

NAME=Jadi

echo
echo "$NAME is learning! Wowww..."
echo
```

> توجه: در صورت نیاز به داشتن فاصله در مقادیر خود، می توانید NAME="Jadi the geeking guy" را نیز انجام دهید.

اگر می خواهید به آرگومان های خط فرمان (Command Line) در اسکریپت پوسته خود دسترسی داشته باشید، از `$1`، `$2`، ... استفاده کنید. می توانید تعداد آرگومان های خط فرمان (Command Line) را از طریق متغیر `$#` بیابید.

### تعویض دستور

گاهی اوقات لازم است خروجی یک دستور را در یک متغیر ذخیره کنید یا به نحوی از آن استفاده کنید. برای این کار می توانید از `$(command)` یا به سادگی \`command\` (Backtick) استفاده کنید. به این دو نمونه نگاه کنید:

```bash
➜  FILES=$(ls -1) # the $FILES variable contains the list of all files

➜  ~ date +'%Y%m%d-%H%m'
20230408-1604
➜  ~ touch backup_`date +'%Y%m%d-%H%m'`.tar
➜  ~ ls
backup_20230408-1604.tar
```

### در حال اجرای اسکریپت ها
در دنیای یونیکس/لینوکس، فایل باید قابل اجرا باشد تا قابل اجرا باشد! :D برای این کار از دستور `chmod` با `+x` استفاده کنید. پس از این مرحله می توانید اسکریپت خود را با دادن مسیر آن به پوسته اجرا کنید. لطفاً توجه داشته باشید که لینوکس به طور پیش‌فرض به دایرکتوری (پوشه) فعلی نگاه نمی‌کند، بنابراین اگر می‌خواهید اسکریپتی را در فهرست فعلی اجرا کنید، باید `./script_name.sh` را اجرا کنید.

راه دیگر برای اجرای یک اسکریپت اجرای `sh` یا `bash` با نام اسکریپت های پوسته به عنوان آرگومان آن است. یعنی `sh my_script.sh`.

در هر دو روش بالا، اسکریپت‌ها در یک فرآیند bash فرزند اجرا می‌شوند و پس از آن *برمی‌گردند* به همان پوسته. اگر می خواهید این مورد را لغو کنید و پوسته فعلی خود را با برنامه ای که می خواهید اجرا کنید * جایگزین* کنید، از دستور داخلی `exec` استفاده کنید. سوئیچ `-c` فرمان را در یک محیط تمیز اجرا می کند.



### شرایط

تا به حال فقط دستورات را یکی یکی اجرا می کردیم. این خیلی _برنامه_ای_ نیست. اگر قرار است مقداری _logic_ در برنامه هایمان داشته باشیم، به _conditions_ و _loops_ نیاز داریم. ابتدا شرایط را با استفاده از دستور `if` پوشش می دهیم. کاربرد آن به این صورت است:

```bash
if [ condition ]
then
   do something
   do another thing
else
   do new things
   even funnier things
fi
```

> توجه: بخش دیگر اختیاری است، `if`، `then`، `fi` کافی است.

شرایط می تواند درست یا نادرست باشد. یک شرایط بسیار ساده `if [ "Linux" = "Linux" ]` است. احمقانه؟ می دانم اما صبر کن؛ ما فقط در حال یادگیری نحو هستیم. لطفاً برای بررسی مساوی بودن دو رشته به _space_ و _`=`_ توجه ویژه ای داشته باشید.

```bash
#!/bin/bash

kernel=$(uname -s)
if [ $kernel = "Linux" ]
then
    echo YES. You are using a Linux
else
    echo "Not a linux :("
fi
```

دستور بررسی شرایط دستور `test` است اما از آنجایی که زیاد استفاده می شود، ما یک میانبر برای آن داریم. به جای `test condition` می توانید `[ condition ]` بنویسید. 

| شرایط | معنی چیست |
| :---: | :--- |
| "a" = "b" | اگر دو رشته برابر باشند \(در اینجا False\ را برمی گرداند) |
| "a" != "b" | رشته a _برابر نیست_ با رشته b |
| 4 - لیتر 40 | اگر 4 _کمتر از_ 40 باشد \(درست\) |
| 5 -gt 15 | اگر 5 _بزرگتر از_ 15 باشد \(نادرست\) |
| 5 -ge 5 | اگر 5 _بزرگتر یا مساوی_ باشد 5 |
| 5 - ل 3 | اگر 5 _کمتر یا مساوی 3 باشد |
| 9 -ne 2 | 9 برابر نیست با 2 \(True\) |
| -f FILENAME | اگر فایل FILENAME وجود داشته باشد |
| -s FILENAME | اگر فایل وجود داشته باشد و اندازه آن بیشتر از 0 باشد \(صفر\) |
| -x FILENAME | اگر فایل وجود داشته باشد و قابل اجرا باشد |

### بخوانید

با استفاده از `read` می توانیم ورودی کاربر را بخوانیم. به این نگاه کن:

```bash
#!/bin/sh

echo "what is your name?"
read NAME

echo "Hello $NAME"

if [ $NAME = "Jadi" ]
then
    echo "Oh I know you!"
else
    echo "I wish I knew you"
fi
echo "Bye"
```

می توانید با استفاده از `-t` زمان انتظار را به پایان برسانید و با استفاده از `-p` درخواستی را نشان دهید. 

```bash
if read -t 10 -p "Server address?" SERVER
then
    echo "Connecting to the $SERVER ..."
else
    echo
    echo "Too late!"
fi
```

حلقه های ###

در برنامه نویسی از حلقه ها برای تکرار بخشی از برنامه ها استفاده می شود. ما 2 حلقه مختلف در Bash داریم. `for` و `while`. حلقه های for به ما اجازه می دهد بخشی از یک برنامه را برای تعداد خاصی از تکرار اجرا کنیم. حلقه `while` زمانی استفاده می شود که بخواهیم بخشی از یک برنامه را تکرار کنیم *در حالی که* یک شرط خاص درست شد. 

#### برای

نحو به این صورت است:

```bash
for VAR in SOME_LIST;
do
  some stuff with $VAR
  some other stuff
done
```

> توجه: `in`، `;`، `do` و `done`.

در هر تکرار، VAR برابر با یکی از عناصر SOME\_LIST خواهد بود. SOME\_LIST می تواند اعداد، نام فایل ها، کلمات و ... باشد.

```bash
for NUM in 1 2 3 4 5 6;
do
    echo $NUM
done
```

اما اگر نیاز به دویدن از 1 تا 42 داشتید چه؟ ما دستور `seq` را برای آن داریم. `seq 1 42` یا مخفف آن `{1..42}` به ما اجازه می دهد یک حلقه را 42 بار اجرا کنیم.

در اینجا می توانیم از متغیرهای غیر عددی نیز استفاده کنیم. این یک مورد استفاده رایج است:

```bash
for FILE in $(ls);
do
    echo $FILE
    wc -l $FILE
done
```

#### در حالی که

این نحو است:

```bash
while [ condition ]
do
    do something
    do anohter thing
done
```

> اگر شرایط شما همیشه صادق باشد، حلقه `while` برای همیشه اجرا می شود. این حلقه _بی نهایت_ نامیده می شود و باید با یک `Ctrl+C` متوقف شود.

این نمونه است:

```bash
VAR=52

while [ $VAR -gt 42 ]
do
    echo VAR is $VAR and it is still greater than 42
    let VAR=VAR-1
done
```

> به استفاده `let` توجه کنید! اگر فقط بگویید `VAR=1` و سپس `VAR=$VAR+1`، VAR برابر با `1+1` به عنوان یک رشته خواهد بود!.

ارسال ### به کاربر اصلی

برای ارسال نامه، باید `mailutils` را نصب کنید. سپس دستور `mail` ایمیل ها را ارسال می کند. با صدور این دستور می توانید نامه را برای کاربر root ارسال کنید:

```bash
jadi@funlife:~$ mail root
Cc:
Subject: Hi there root
hello there. This is my mail
```

و root این ایمیل را دریافت خواهد کرد. او می تواند آن را با استفاده از دستور `mail` بخواند.

اگر نیاز به ارسال ایمیل در یک اسکریپت دارید، فقط این کار را انجام دهید:

```bash
$ echo "Body!" | mail -s "Subject" root
```

## مقادیر را برگرداند

در دنیای یونیکس، برنامه‌ها پس از اتمام، مقادیر را برمی‌گردانند. اگر C را برنامه ریزی کرده اید، این `return 0` در پایان است. معمولاً 0 به معنای اجرای موفقیت آمیز است. این مقدار بازگشتی را می توان با استفاده از متغیر `$?` خواند / بررسی کرد. 

```bash
jadi@ubuntuserver:/etc/skel$ touch /chert
touch: cannot touch '/chert': Permission denied
$ echo $?
1
$ touch /tmp/11
$ echo $?
0
$ test -e /
$ echo $?
0
$ test -e /nonexist
$ echo $?
1
$ dummycommand
dummycommand: command not found
$ echo $?
127
```

برای برگرداندن مقادیر از اسکریپت های پوسته خود، از دستور `exit` استفاده کنید. برای خروج موفقیت آمیز بگویید `exit 0`.
