## اهداف

* استفاده از دستورات تکی شل و زنجیره‌ای از دستورات تک‌خطی برای انجام کارهای پایه در خط فرمان.
* استفاده و مدیریت محیط شل؛ شامل تعریف، فراخوانی و Export کردن متغیرهای محیطی (Environment Variables).
* استفاده و ویرایش تاریخچه دستورات (Command History).
* فراخوانی و اجرای دستورات در داخل و خارج از مسیرهای تعریف‌شده (`PATH`).

### شل‌ها و شل Bash (Shells and Bash)

<iframe width="560" height="315" src="https://www.youtube.com/embed/X-zq9-FhjOA" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

شما دستورات خود را در یک **شل (Shell یا همان پوسته)** اجرا می‌کنید. شل رابط خط فرمان (CLI) شما با سیستم‌عامل است و گزینه‌های متنوعی برای آن وجود دارد. برای دسترسی به شل، می‌توانید سیستم را در حالت متنی (Text Mode) بوت کنید یا یکی از برنامه‌های **شبیه‌ساز ترمینال (Terminal Emulator)** را در محیط گرافیکی خود اجرا نمایید؛ مانند `gnome-terminal`، `konsole`، `xterm` و غیره.

پس از باز کردن ترمینال یا ورود به حالت متنی، شما درون شل قرار دارید و می‌توانید دستورات را تایپ و اجرا کنید. با وجود اینکه `bash` (مخفف GNU Bourne Again Shell) رایج‌ترین شل در دنیای لینوکس است، ممکن است از شل‌های دیگری مثل `zsh`، `dash`، `ksh` یا `csh` نیز استفاده کنید.

برای اینکه ببینید شل پیش‌فرض سیستمی `sh` به کدام شل پیوند (Link) خورده است، می‌توانید دستور زیر را اجرا کنید:

```bash
$ readlink /bin/sh
```

یا متغیر محیطی `$SHELL` خود را چاپ کنید:

```bash
$ echo $SHELL
```

شل Bash دارای یک‌سری دستورات **داخلی (Built-in)** است که بدون نیاز به هیچ برنامه خارجی متوجه آن‌ها می‌شود (مثل `cd`، `break`، `exec` و...)؛ اما اگر دستوری برایش ناشناخته و غیرداخلی باشد، تلاش می‌کند آن را به عنوان یک فایل اجرایی خارجی در سیستم پیدا و اجرا کند.

با دستور `type` می‌توانید نوع هر دستور را مشخص کنید:

```text
[jadi@fedora ~]$ type cd
cd is a shell builtin
[jadi@fedora ~]$ type ls
ls is aliased to `ls --color=auto'
[jadi@fedora ~]$ type ping
ping is /usr/bin/ping
```

## دستورات `cd`، `pwd` و `uname`
### دستور cd
قبلاً کاربرد دستور `cd` را زیاد دیده‌اید :) این دستور دایرکتوری کاری شما را تغییر می‌دهد؛ از جمله رجوع به `.` (دایرکتوری جاری) و `..` (دایرکتوری والد یا یک پله بالاتر).

به دو روش می‌توانید به مسیر دایرکتوری‌ها اشاره کنید:

1. **مسیرهای مطلق (Absolute Paths):** مانند `/home/jadi/lpic1/lesson3.1` (که از ریشه `/` شروع می‌شود).
2. **مسیرهای نسبی (Relative Paths):** مانند `lpic1/lesson3.1`. در این حالت چون ابتدای مسیر با `/` شروع نشده، شل Bash دایرکتوری `lpic1` را نسبت به جایی که هم‌اکنون در آن قرار داریم پیدا می‌کند.

> کاراکتر `~` مخفف **دایرکتوری خانگی (Home Directory)** کاربری است که دستور را اجرا می‌کند.

اگر دستور `cd` را بدون هیچ آرگومانی اجرا کنید، مستقیماً شما را به Home Directory خودتان می‌برد؛ بنابراین این سه دستور دقیقاً یکسان عمل می‌کنند:

```bash
cd
cd ~
cd $HOME
```

### دستور pwd
مسیر دایرکتوری جاری (Current Working Directory) را به شما نمایش می‌دهد:

```text
[jadi@fedora lesson3.1]$ pwd
/home/jadi/lpic1/lesson3.1
```

### دستور uname
اطلاعاتی درباره سیستم و هسته لینوکس به شما می‌دهد. سوییچ‌های رایج آن عبارتند از:

| گزینه | توضیحات |
| :--- | :--- |
| `-s` | چاپ نام هسته (کرنل). اگر گزینه‌ای مشخص نشود، این حالت پیش‌فرض است. |
| `-n` | چاپ نام گره یا همان نام میزبان (Hostname). |
| `-r` | چاپ نسخه انتشار کرنل (Kernel Release). این گزینه در کار با ماژول‌ها بسیار استفاده می‌شود. |
| `-v` | چاپ تاریخ و نسخه ساخت کرنل (Kernel Version). |
| `-m` | چاپ معماری سخت‌افزاری دستگاه (مانند x86_64 یا aarch64). |
| `-o` | چاپ نام سیستم‌عامل. |
| `-a` | چاپ تمام اطلاعات بالا به صورت یکجا. |

مثال:

```text
[jadi@fedora lesson3.1]$ uname -a
Linux fedora 5.14.0-60.fc35.aarch64 #1 SMP Mon Aug 30 16:30:42 UTC 2021 aarch64 aarch64 aarch64 GNU/Linux
```

## دریافت راهنما (Getting Help)
بیشتر دستوراتی که با آن‌ها کار می‌کنیم یک مستند و راهنمای کامل دارند که از طریق دستور `man` قابل دسترسی است. این دستور به طور پیش‌فرض از ابزار پیمایش `less` استفاده می‌کند و شامل توضیحات، سوییچ‌ها، پارامترها و مستندات ابزارهاست.

می‌توانید با خواندن راهنمای دستور ساده `yes` با محیط `man` آشنا شوید:

```bash
$ man yes
```

صفحات man به بخش‌های (سکشن‌های) مختلفی تقسیم شده‌اند. با خواندن راهنمای خود `man` می‌توانید این بخش‌ها را بررسی کنید:

```bash
$ man man
$ man 5 passwd
```

## کاراکترهای ویژه و مفهوم Quoting / Escaping
در دنیای کامپیوتر و شل، برخی کاراکترها معنی خاصی دارند. مثلاً در Bash، کاراکتر `*` به تمامی فایل‌های مسیر جاری بسط (Expand) پیدا می‌کند. در این مواقع اگر بخواهید از خود این کاراکتر به صورت متنی و بدون اثرگذاری معنای خاصش استفاده کنید، باید آن را **Quote** یا **Escape** کنید. در اکثر موارد این کار با قرار دادن یک بک‌اسلش (`\`) قبل از آن کاراکتر انجام می‌شود:

```bash
$ echo 2 \* 3 = 6
2 * 3 = 6
```

اگر قصد دارید از کاراکترهای زیر در دستورات خود به عنوان متن عادی استفاده کنید، باید اثر آن‌ها را خنثی (Escape یا Quote) کنید:

`* ?[]'"\$;&()|^<>`

*(توجه داشته باشید که کاراکتر فاصله/Space نیز جزو این کاراکترهای خاص است).*

> همان‌طور که دیدید، خود کاراکتر `\` نیز یک کاراکتر ویژه است؛ پس اگر بخواهید خود علامت بک‌اسلش را چاپ کنید، باید با یک بک‌اسلش دیگر آن را خنثی کنید: `\\`

علاوه بر خنثی‌سازی، از `\` برای تولید برخی کاراکترهای کنترلی ویژه نیز استفاده می‌شود. مثلاً چون نمی‌توان کلید Return/Enter را مستقیماً داخل یک رشته تایپ کرد، از دنباله فرار `\n` (سطر جدید) استفاده می‌کنیم:

```text
jadi@funlife:~$ echo -e "hello\nthere"
hello
there
```

برخی از مهم‌ترین این کاراکترها:

| دنباله Escape | عملکرد / توضیح |
| :--- | :--- |
| `\a` | هشدار صوتی (Alert / Bell) |
| `\b` | کلید Backspace (حذف یک کاراکتر به عقب) |
| `\c` | حذف خط جدید انتهایی (مشابه آپشن `-n` در echo) |
| `\f` | رفتن به صفحه بعد (Form Feed) |
| `\n` | رفتن به سطر جدید (New Line) |
| `\r` | بازگشت به ابتدای سطر (Carriage Return) |
| `\t` | تب افقی (Horizontal Tab) |

همچنین در شل Bash می‌توانید از `\` برای شکستن یک دستور طولانی به چند خط استفاده کنید:

```bash
$ echo You know slashes! But this \
is another \
usage
You know slashes! But this is another usage
```

## متغیرهای محیطی شل (Shell Environment Variables)

<iframe width="560" height="315" src="https://www.youtube.com/embed/KMvc1SyPgjw" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

**متغیرهای محیطی (Environment Variables)** شامل تنظیمات و اطلاعاتی درباره شل و محیط سیستم هستند؛ برای مثال ویرایشگر پیش‌فرض شما در متغیر `EDITOR` تنظیم می‌شود. می‌توانید مقدار یک متغیر را به این صورت بررسی کنید:

```bash
[jadi@fedora ~]$ echo $EDITOR
/usr/bin/nano
```

برای مشاهده تمامی متغیرهای تعریف‌شده، می‌توانید از دستور `env` یا `set` استفاده کنید.

برخی از پرکاربردترین متغیرهای محیطی در Bash:

| نام متغیر | کاربرد / توضیحات |
| :--- | :--- |
| `USER` | نام کاربری که در حال حاضر وارد سیستم شده است |
| `PATH` | فهرستی از مسیرهای دایرکتوری برای جستجوی فایل‌های اجرایی دستورات (که با علامت `:` از هم جدا شده‌اند) |
| `EDITOR` | ویرایشگر متن پیش‌فرض سیستم |
| `HISTFILE` | فایلی که تاریخچه دستورات در آن ذخیره می‌شود (معمولاً `~/.bash_history`) |
| `HOSTNAME` | نام میزبان (Hostname) سیستم |
| `PS1` | ساختار اعلان خط فرمان (Prompt) |
| `UID` | شناسه عددی کاربر جاری (User ID) |
| `HOME` | مسیر دایرکتوری خانگی کاربر |
| `PWD` | مسیر دایرکتوری کاری فعلی |
| `SHELL` | مسیر شل جاری کاربر |
| `$$` | شناسه فرآیند (PID) شل جاری |
| `$PPID` | شناسه فرآیند والد (Parent PID) که این شل را اجرا کرده است |
| `$?` | کد خروج (Exit Code) آخرین دستور اجرا شده |

هنگام خواندن مقدار متغیر، باید علامت `$` را به ابتدای نام آن اضافه کنید:

```text
$ echo $USER $UID
jadi 1000
$ echo $SHELL $HOME $PWD
/bin/bash /home/jadi /home/jadi/lpic
```

برای تعریف، تغییر مقدار یا حذف یک متغیر:

```bash
$ MYMOOD=happy
$ echo I am $MYMOOD
I am happy
$ MYMOOD="Even Happier" # وجود فاصله نیاز به دابل‌کوتیشن دارد
$ unset MYMOOD
```

اگر می‌خواهید برنامه‌ها و زیرپروسه‌هایی که از این شل اجرا می‌شوند نیز به متغیر شما دسترسی داشته باشند، باید آن را با دستور `export` صادر (اکسپورت) کنید:

```bash
$ export MYMOOD
$ export YOURMOOD="Not Confused"
```

> تنظیمات سراسری Bash در مسیر `/etc/profile` قرار دارند و هر کاربر تنظیمات اختصاصی خود را در فایل‌های `~/.profile` و `~/.bash_profile` و `~/.bash_logout` نگهداری می‌کند. اگر قصد ایجاد تغییرات دائمی دارید، باید آن‌ها را در این فایل‌ها قرار دهید.

## متغیر PATH
وقتی دستوری را در خط فرمان تایپ می‌کنید، اگر دستور از نوع داخلی (Built-in) باشد، شل بلافاصله آن را اجرا می‌کند. در غیر این صورت، شل سراغ مسیرهای مشخص‌شده در متغیر `PATH` می‌رود و آن‌ها را یکی‌یکی جستجو می‌کند تا فایل اجرایی مربوطه را بیابد. اگر فایل را در هیچ‌کدام پیدا نکند، خطای دستور یافت نشد (command not found) می‌دهد. اگر بخواهید دستوری خارج از این مسیرها را اجرا کنید، باید مسیر مستقیم آن را به شل بدهید:

```text
$ echo $PATH
/home/jadi/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/games:/usr/local/games
```

مثلاً اگر بخواهیم دستور `tar` را پیدا کنیم، با دستورات `which`، `type` و `whereis` می‌توانیم محل آن را بررسی کنیم:

```text
jadi@funlife:~$ which tar
/bin/tar
jadi@funlife:~$ type tar
tar is /bin/tar
jadi@funlife:~$ whereis tar
tar: /usr/lib/tar /bin/tar /usr/include/tar.h /usr/share/man/man1/tar.1.gz
```

یک مثال ملموس دیگر دستور `ping` در فدورا است:

```text
[jadi@fedora ~]$ whereis ping
ping: /usr/bin/ping /usr/sbin/ping /usr/share/man/man8/ping.8.gz
[jadi@fedora ~]$ which ping
/usr/bin/ping
[jadi@fedora ~]$ /usr/sbin/ping 4.2.2.4
PING 4.2.2.4 (4.2.2.4) 56(84) bytes of data.
64 bytes from 4.2.2.4: icmp_seq=1 ttl=50 time=160 ms
```

> به همین دلیل است که برای اجرای یک برنامه در دایرکتوری جاری باید از `this_program/.` استفاده کنید؛ یعنی صراحتاً به شل می‌گویید این فایل در همین مسیر فعلی است، زیرا دایرکتوری جاری (`.`) به دلایل امنیتی به طور پیش‌فرض درون `PATH` قرار ندارد.

## تاریخچه دستورات (Command History)
شل Bash تاریخچه دستورات اجرا شده را در فایل `~/.bash_history` ذخیره می‌کند. می‌توانید این فایل را با دستور `cat` ببینید یا دستور `history` را اجرا کنید. همچنین کلیدهای میانبر زیر برای پیمایش در تاریخچه کاربرد دارند:

| کلید میانبر | عملکرد |
| :--- | :--- |
| کلیدهای جهت‌نما بالا و پایین | حرکت در تاریخچه دستورات قبلی و بعدی |
| `Ctrl + R` | جستجوی معکوس در تاریخچه (Reverse Search) |
| `Ctrl + O` | اجرای دستوری که با `Ctrl + R` پیدا کرده‌اید |
| `!!` | اجرای مجدد آخرین دستور |
| `!10` | اجرای دستور شماره ۱۰ در لیست تاریخچه |
| `!text` | جستجوی معکوس و اجرای اولین دستوری که با متن مورد نظر شروع می‌شود |

> اگر می‌خواهید تاریخچه سشن فعلی را موقتاً پاک کنید یا غیرفعال سازید، می‌توانید متغیر `HISTSIZE=0` را تنظیم کنید.

## خروج از شل (Exiting the Shell)

دستور `exit` یا فشردن کلیدهای `Ctrl + D` باعث خروج از شل فعلی می‌شود.

اگر دستوری را درون پرانتز بنویسید (مانند `(ls; date)`)، آن دستورات درون یک **شل فرعی (Subshell)** مجزا اجرا می‌شوند. همچنین دستور `exec` فرمانی را اجرا کرده و بلافاصله پروسه شل فعلی را می‌بندد و با برنامه جدید جایگزین می‌کند.
