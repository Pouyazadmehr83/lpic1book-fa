کاندیداها باید بتوانند اولویت های اجرای فرآیند را مدیریت کنند.

## اهداف
* اولویت پیش فرض کاری که ایجاد می شود را بدانید.
* برنامه ای را با اولویت بالاتر یا کمتر از پیش فرض اجرا کنید.
* اولویت یک فرآیند در حال اجرا را تغییر دهید.

## شرایط
*خوب
* ps
* `renice`
* بالا

در یک ماشین لینوکس، ممکن است 100 فرآیند به طور همزمان اجرا شوند و برای CPU و RAM بیشتر رقابت کنند. خبر خوب این است که می‌توانید در این مسابقه به برخی از فرآیندها اولویت بالاتر یا پایین‌تری (یا خوب بودن) بدهید. بیایید نگاهی به نمونه خروجی `top` بیندازیم:

ستون **NI** نشان می دهد که این فرآیند چقدر **خوب است. هر چه فرآیند بهتر باشد، CPU کمتری می خواهد. مقادیر `nice` می توانند از 20- تا 19 باشند. برای تفسیر این مقدار، به این شکل نگاه کنید: یک فرآیند با nice = **-20** ANGRY است و اولویت بیشتری برای CPU و RAM دارد، در حالی که یک فرآیند با nice = **19** بسیار خوب است و به **فرایندهای** دیگر اجازه می دهد از منابع قبل از او استفاده کنند.

مقدار پیش‌فرض برای `nice` معمولاً روی 0 تنظیم می‌شود. این را می توان با:

```
$ nice
0
```

همچنین می توانید با استفاده از دستور `ps`، خوب بودن را بررسی کنید:

### تنظیم زیبایی

اگر نیاز به تغییر سطح زیبایی یک برنامه دارید، می‌توانید آن را با دستور `nice` و سوئیچ `-n` \(برای خوب\) اجرا کنید:

```text
$ nice -n 19 echo "I am running!"
I am running!
$ nice -n -20 echo "I am running!"
nice: cannot set niceness: Permission denied
I am running!
$ sudo nice -n -20 echo "I am running!"
I am running!
```

همانطور که در مثال بالا می توانید، فقط ریشه می تواند زیبایی با اولویت بالا (زیر 0) را صادر کند.

> اگر فرمانی را با `nice` بدون `-n` اجرا کنید، پیش‌فرض `-n 10` خواهد بود.

```text
$ nice xeyes &
[1] 15217
$ ps -l
F S   UID   PID  PPID  C PRI  NI ADDR SZ WCHAN  TTY          TIME CMD
0 S  1000 15044 15035  0  80   0 -  7455 wait   pts/29   00:00:00 bash
0 S  1000 15217 15044  0  90  10 - 12522 poll_s pts/29   00:00:00 xeyes
0 R  1000 15218 15044  0  80   0 -  4680 -      pts/29   00:00:00 ps
```

### تغییر اولویت ها

دستور `renice` را می توان برای تغییر _خوبی_ فرآیندهای در حال اجرا خود (یا موارد دیگر در صورتی که روت هستید) استفاده کرد:

```text
$ ps -ef | grep firefox
jadi     13605 11226 30 08:28 ?        00:10:13 /usr/lib/firefox/firefox
jadi     15192 15044  0 09:01 pts/29   00:00:00 grep firefox
$ sudo renice -n -10 13605
13605 (process ID) old priority 5, new priority -10
```

> همچنین می‌توانید `r` را در دستور `top` فشار دهید تا یک فرآیند دوباره شروع شود.
